# 2025_machine_learning_final_project
# Traffic Flow Prediction with Spatiotemporal Graph Neural Networks

Machine Learning Final Project

## Project Overview

This project investigates traffic flow forecasting using machine learning and graph neural networks (GNNs).

The objective is to model both:

- Spatial dependencies between road intersections
- Temporal dynamics of traffic flow

Three different architectures were implemented and evaluated, ranging from traditional neural networks to spatiotemporal graph learning models.

## Models

### Model 1
Multilayer Perceptron (MLP)

### Model 2
Graph Convolutional Network (GCN)

### Model 3
GCN-LSTM
